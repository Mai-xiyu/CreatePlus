# CreatePlus

面向创造模式的建筑工具箱，Minecraft **1.20.1 / Forge 47+**。

纯客户端模组：服务器不需要安装，也不会因为版本不一致被拒绝进服。
所有编辑操作要么走原版命令（有 OP 时），要么走创造模式的放置/破坏数据包，
因此在原版服务端上同样可用。

## 安装

把构建出来的 jar 丢进 `mods/` 即可。

```bash
./gradlew build      # 产物在 build/libs/
```

## 快速上手

| 按键 | 作用 |
| --- | --- |
| `F9` | 屏幕左上角的快捷菜单（键盘操作） |
| `右 Shift` | 完整的鼠标操作面板（ClickGUI） |
| `F6` | 灵魂出窍 |
| `F7` | 命令工作室（AI / OOC） |
| `F8` | 退出 HUD 编辑模式 |
| `C`（按住） | 视角缩放 |
| `左 Ctrl` | 修饰键，配合滚轮调参数 |
| 未绑定 | 生成键（落地预览 / 填充选区）、撤销区域操作 |

按键都能在原版「选项 → 控制」里改。配置保存在 `.minecraft/createplus/createplus.json`，
改动即时写盘。

典型的一次区域编辑：

1. 开启 **选区工具**，手持木铲左键点起点、右键点终点；
2. `/createplus fill hollow` 或按填充键，用手上的方块填充；
3. 不满意就 `/createplus undo`，操作太大想中断就 `/createplus cancel`。

铺一整层地板：开启 **放置限制**（默认锁同一水平层），手持方块按住右键扫过去，
准星滑到侧面也不会往上砌一格。松开右键就重新取锚点。

## 生成式建造

这一组的共同点是**先看到，再落地**：预览是半透明的实体，跟着准星走，
参数用滚轮实时调，确认了才变成真方块——不用「建完发现不对再撤销」。

```
/createplus shape torus 12 3     # 圆环，环半径 12
/createplus palette grab         # 把快捷栏里的方块抓成材质调色板
/createplus build                # 落地
```

**几何体工坊**给的是手工摆不出来的形状：球、椭球、圆柱、圆锥、棱锥、圆环、
穹顶、拱门、螺旋。拱门的两条腿是椭圆环带和地面相交自然形成的，螺旋是沿曲线
盖球得到的——半径 1 是藤蔓，大一点就是旋转坡道。空心时只生成外壳，壁厚可调。

**样条曲线**用来修没有台阶感的曲线。手持控制杖点几个控制点，中间用
Catmull-Rom 连成一条**穿过所有控制点**的平滑曲线，再按粗细铺成管道。
盘山公路、河道、悬索、藤蔓这些东西，长方体选区拼不出来。张力从 0 调到 1
会从圆弧逐渐变成折线，也可以闭合成环。

**材质调色板**解决「一眼就看出是填出来的」。把要混的方块摆进快捷栏抓取，
生成时用三维连续噪声取材质——相邻方块噪声值接近，同种材质会连成一片片斑块，
而不是随机撒盐。同一种方块多占几格快捷栏就是给它加权重。调色板对区域填充、
几何体工坊、样条曲线同时生效。

预览只画外表面，实心球内部那些看不见的面不会浪费顶点；面数超上限时自动
退回只画包围盒，不会因为一个大形状把帧数拖死。

## 功能

### 建筑

| 功能 | 说明 |
| --- | --- |
| 选区工具 | 手持指定物品左右键划出长方体选区，填充 / 复制 / 导出共用这一个选区 |
| 快速建造 | 去掉放置方块的冷却 |
| 无限放置 | 创造模式下自动补满手上的方块 |
| 区域填充 | 实心、空心、四壁、边框、只填空气、清空六种模式，带撤销 |
| 区域复制 | 复制选区并粘贴到别处，支持旋转、镜像与沿方向阵列重复 |
| 镜像建造 | 沿指定平面同步放置对称方块 |
| 几何体工坊 | 球 / 椭球 / 圆柱 / 圆锥 / 棱锥 / 圆环 / 穹顶 / 拱门 / 螺旋，带实时全息预览 |
| 样条曲线 | 控制点连成 Catmull-Rom 平滑曲线，再铺成有粗细的管道 |
| 材质调色板 | 快捷栏多种方块按连续噪声混合，出来的墙面像手工细化过 |
| 放置限制 | 按住右键连放时，把方块锁在同一层 / 面 / 竖列 / 直线上 |
| 空气放置 | 准星瞄着空气也能在视线落点放方块（需创造） |
| 自动搭路 | 向前走时自动在脚下续方块（需创造） |
| 量尺 | Ctrl+右键两点测距，显示长宽高与体积（需创造） |
| 层切面 | 按 Y 层锁定建造，带半透明层平面（需创造） |
| 精确拾取 | 中键抓取完整方块状态与方块实体 NBT（需创造） |
| 状态剪贴板 | Ctrl+中键复制方块状态，放置同种方块时自动粘贴（需创造） |
| 快捷栏随机 | 连放时从快捷栏随机抽方块（需创造） |
| 准星替换 | Ctrl+左键用手上的方块盖掉准星方块（需创造） |
| 洪水填充 | 潜行+Ctrl+右键，填充相连的同种方块（需创造） |
| 范围放置 | 笔刷式放置，立方体 / 球 / 圆盘 / 十字 |
| 范围破坏 | 笔刷式破坏，同样四种形状 |
| 方块变色 | 按住修饰键滚轮切换羊毛、混凝土等同类方块的颜色 |
| 建筑导出 | 把选区写成 `.mcfunction` 文件 |
| 自动搭桥 | 脚下自动垫方块，可选一直搭 / 潜行搭 / 跳跃搭 |

大批量编辑走的是逐刻队列，不会一次性把命令全塞给服务器，屏幕下方会显示进度。

### 创造标签页

- **隐藏物品**：所有不出现在任何原版标签页里的物品（屏障、命令方块等）。
- **刷怪蛋**：每个可召唤实体一颗蛋。原版没做蛋的实体用 `EntityTag` 顶上，纯净服也能用。
- **在线玩家背包（动态）**：预留最多 16 个标签页，打开创造栏时按当前在线玩家刷新。
  每位玩家一页，含盔甲、副手、快捷栏与主背包。
  单人 / 本机主机可读完整背包；远端多人服上别人只显示可见装备（原版不同步他人主背包）。

### 系统

**性能优化**：原有粒子/实体开关之外，合入 Graphene 风格客户端优化：水下跳过天空、
无发光跳过描边、远处粒子 LOD、远处箱子跳过 BER、失焦限帧、竹子全亮等。
功能需开启后各子开关才生效。原版「选项」界面有快捷入口。

**命令工作室**（`F7`，需开启 `command_studio`）：
- **AI**：把本地已同步指令树发给兼容 OpenAI 的 API；模式可选普通指令 / OOC / 两者；
  返回后用游戏 Brigadier 校验，失败自动带错误重试一次；**只展示/复制，不执行**
- **OOC**：可让 AI 直接生成，或把普通指令用本地模板包装
- **NBT 键补全**：自研轻量建议

**HUD 编辑**：开启「HUD 编辑」后可拖动信息面板 / 方块信息 / Ping / 记分板，
以及血量·盔甲·饥饿、快捷栏、经验条、Boss 栏、状态效果；**仅 F8 退出**。

**地图画**：开启「地图画」选图片，按 N×M（每张 128×128，最大 9×9）生成 `filled_map`，
写入创造「已保存的快捷栏」。需单人世界或局域网主机（地图数据在服务端存档里）。

## 命令

主命令 `/createplus`，别名 `/cplus` 和 `/features`（三者完全等价）。

```
/createplus                      列出所有功能
/createplus <功能>                开关某个功能
/createplus toggle <功能>         同上，显式写法
/createplus set <功能> <设置> <值>  改设置
/createplus reset <功能>          恢复该功能的默认设置
/createplus gui                  打开 ClickGUI
/createplus hud                  开关快捷菜单
/createplus help [功能]           总帮助 / 单个功能的用法

/createplus sel                  查看当前选区
/createplus sel clear            清空选区
/createplus copy                 复制选区
/createplus paste                粘贴
/createplus stack <份数> [方向]    沿一个方向阵列重复选区
/createplus fill [模式]           填充选区

/createplus shape <形状> [半径] [高度]   选择参数化几何体
/createplus shape pin            把预览钉在原地
/createplus build                把当前预览落成方块
/createplus curve clear          清空样条控制点
/createplus palette grab|list|clear      材质调色板
/createplus undo                 撤销上一次区域操作
/createplus cancel               中断进行中的批量操作

/createplus export <名字>         把选区导出成 .mcfunction
/createplus import <名字>         预览一个建筑文件
/createplus confirm              确认导入预览中的建筑

/createplus time <预设>           本地时间
/createplus weather <类型>        本地天气
/createplus give <物品> [数量]     创造模式取物品
```

命令全部带 Tab 补全。建筑文件存放在 `.minecraft/createplus/buildings/`。

## 说明

- 撤销依赖 `setblock`，需要 OP 权限；没有 OP 时区域编辑会退回数据包方式，
  此时无法撤销。
- 穿墙、超远交互这类功能受服务端校验限制，联机时行为可能与单人不同。
- 请勿用于破坏他人建筑。
